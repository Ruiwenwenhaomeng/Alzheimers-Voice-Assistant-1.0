# 科普助手多模型切换

科普助手支持以下回答模型：

| 服务商 | 默认模型 | 后端固定 API 地址 |
|---|---|---|
| 系统默认 | 由 `start.ps1` / 环境变量决定 | 由后端配置决定 |
| DeepSeek | `deepseek-chat` | `https://api.deepseek.com` |
| Kimi | `kimi-k2.6` | `https://api.moonshot.cn/v1` |
| 智谱 GLM | `glm-5.2` | `https://open.bigmodel.cn/api/paas/v4` |
| 通义千问 | `qwen-plus` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |

模型名称可以在前端修改，以便使用服务商账户已开通的其他文本模型。后端不接受自定义 API 地址，只允许调用代码内列出的官方地址。

## 使用方法

1. 运行 `start.ps1` 并打开科普助手。
2. 展开对话上方的“回答模型”。
3. 选择服务商，填写模型名称和该服务商的 API Key。
4. 点击“保存并切换”。下一次提问立即使用新配置，不需要重启后端。
5. 顶部徽标会显示当前生效的服务商和模型；回答的检索摘要也会注明本次使用的模型。

每个服务商的模型名和 Key 会分别保存，来回切换时不需要重复填写。点击“清除此 Key”会删除当前服务商的本地 Key，并切回系统默认。

## Key 保存边界

- 配置按登录用户名隔离；未登录时按匿名浏览器 ID 隔离。
- Key 保存于当前浏览器的 `localStorage`，不会写入 MySQL、Redis、对话消息或项目配置文件。
- 提问时 Key 通过请求体发送到本机 Java 后端，仅在该请求的内存中用于调用服务商。
- 后端错误日志不记录 Key，配置对象的字符串输出也会强制脱敏。
- 浏览器本地存储并不是密码保险箱。不要在公共电脑保存 Key；不再使用时应点击清除，并在服务商控制台定期轮换或撤销 Key。

## 联网检索说明

本地知识库命中时，四家模型都可以生成流式回答。现有带“实时来源”的服务端联网检索协议属于 DeepSeek 专用能力，因此系统默认/DeepSeek 配置可继续使用该能力；选择 Kimi、GLM 或千问且本地知识不足时，系统会安全拒答，不会悄悄改用其他模型，也不会让模型脱离资料自行编造。

通义千问、GLM 和 Kimi 各自的联网工具协议并不完全兼容，后续如需接入，应分别实现来源解析与计费提示，不能只添加一个通用开关。

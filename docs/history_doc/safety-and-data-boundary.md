# Safety And Data Boundary

## Medical Boundary

本助手提供知识普及和风险筛查，不提供诊断、排除诊断或治疗方案。所有筛查结果都应显示医疗免责声明，并建议用户结合专业医疗评估理解结果。

语音筛查只能表达为风险提示。默认参考服务在没有经过验证的模型前，应返回 `INCONCLUSIVE` 或需要复核的结果。

## Escalation Boundary

当用户描述突发言语困难、口角歪斜、单侧无力、意识异常等急性表现时，助手应提示立即联系当地急救服务。

当用户描述记忆、语言、判断、生活能力持续受影响时，助手应建议预约记忆门诊、神经内科、老年医学科或正规医疗机构评估。

## Data Boundary

语音、转写文本、筛查结果、认知量表和病史都应视作敏感健康相关信息。

必须支持：

- 明确知情同意。
- 服务端保存同意版本和时间。
- 最小化采集。
- 访问控制和用户归属校验。
- 用户主动删除语音、结果和报告。
- 模型版本、数据集版本和免责声明版本留痕。

## Model Release Boundary

任何会输出非 `INCONCLUSIVE` 风险等级的模型，都必须在上线前完成：

- 数据来源、授权和使用许可检查。
- 训练、验证、测试和外部测试主体隔离。
- 独立测试集敏感度、特异度、准确率和覆盖率评估。
- 关键亚组公平性检查。
- 阈值、模型版本和评估结果归档。

没有通过验证的模型不得包装成临床可用结果。

# Product MVP

## Goal

构建一个面向用户和家属的智能助手，提供阿尔茨海默病相关知识普及、语音风险筛查、结果解释和就医建议。

## Core User Flow

1. 用户注册或登录。
2. 用户阅读知情同意，确认语音和健康相关数据处理边界。
3. 用户录制自然叙述语音，或上传 PCM WAV 文件。
4. 系统进行音频格式和质量检查。
5. 筛查服务返回转写、质量问题、风险等级、风险分数、模型版本和解释特征。
6. 后端保存结构化筛查记录，并明确标注结果不能替代临床诊断。
7. 用户查看历史记录、生成报告，或删除语音和关联报告。
8. 用户在科普助手中继续询问症状、风险因素、照护和就医问题。

## MVP Features

- 登录、注册、角色权限和基础资料。
- 科普问答接口和前端聊天入口。
- 音频上传、服务端 WAV 校验、知情同意版本留痕。
- Python 筛查服务接口，默认未验证模型只返回 `INCONCLUSIVE`。
- 结构化筛查报告、历史记录、PDF 报告和数据删除。
- 模型评估脚本、数据集校验脚本和上线前验证文档。
- Docker Compose MySQL/Redis 开发依赖。

## Not In MVP

- 临床诊断。
- 未经验证的自动高风险判定上线。
- 真实敏感数据默认入库或入仓。
- 面向医生的诊疗建议生成。

## Next Engineering Steps

3. 接入经过授权的 ASR 和风险模型插件。
4. 使用独立临床标注数据集跑模型验证和公平性检查。
5. 为报告生成和历史结果增加端到端测试。
